# إضافة النسخ الاحتياطي للرواتب

تستقبل الإضافة نسخ التطبيق من الشبكة المحلية وتحفظ كل نسخة مستقلة داخل `/data/backups`. تُضمّن بيانات الإضافة في النسخ الاحتياطي لـ Home Assistant؛ احتفظ أيضاً بنسخة على وسيط آخر. لا تحذف الإضافة القديمة النسخ السابقة تلقائياً، لذا راقب المساحة.

1. في Home Assistant: الإعدادات ← الإضافات ← متجر الإضافات ← المستودعات، أضف `https://github.com/3hasnawi/ios-app` ثم ثبّت Salary Backup.
2. افتح إعدادات الإضافة واكتب رمز وصول عشوائياً لا يقل عن 32 حرفاً إنجليزياً ورقماً، من دون مسافات، ثم احفظ وشغّل الإضافة. لا تشارك الرمز.
3. في تطبيق الرواتب افتح الإعدادات ← النسخ الاحتياطي ← سيرفر النسخ المحلي؛ أدخل عنوان Home Assistant مثل `http://192.168.1.10:8765` ونفس الرمز، ثم فعّل السيرفر واختر النسخ بعد الاستيراد أو الجدول الدوري.
4. اضغط «نسخ الآن» وانتظر نجاح النسخ. لاسترجاع آخر نسخة استخدم «استرجاع آخر نسخة من السيرفر» وراجع التأكيد قبل الاسترجاع.

الاتصال في هذه النسخة HTTP داخل الشبكة المحلية **غير مشفّر**؛ استخدم شبكة موثوقة فقط ولا تفتح المنفذ على الإنترنت. نسخ الخلفية غير مضمون بوقت دقيق، وiOS يحدد وقت التنفيذ. يستمر السيرفر بحفظ النسخ الماضية؛ تسجيل نجاح التطبيق يؤكد الاستلام والتحقق من الملف، ولا يحل محل نسخة احتياطية مستقلة.
