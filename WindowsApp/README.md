# الرواتب لويندوز — نسخة قيد التطوير

مشروع WinUI 3 يقرأ نسخة الرواتب (حتى الصيغة 4) من ZIP أو من سيرفر النسخ المحلي. لا يغيّر السيرفر أو ملف المصدر ولا يزامن تعديلات. تعرض الواجهة ملخص الرواتب للشهر، بحث الموظفين والملاك والجهات والكتب، تفاصيل الموظف والملاك وتصدير تقرير الملاك PDF، كشف البنك، كشف جهات التنفيذ وفحوص تدقيق أولية. يمكن حفظ كتاب PDF من النسخة وفتحه، وتصدير كشوف الجهات وبنود الرواتب إلى Excel وPDF، وحالات التدقيق إلى Excel، بخط Arial واتجاه من اليمين إلى اليسار. تعرض بنود الرعاية وصندوق الشهداء وعقد الإطعام تفاصيلها الخاصة للمعاينة.

حساب كشف البنك يتبع قواعد تطبيق الآيفون: الكاش والبطاقة وغير المصنف، البنود المحددة، استقطاعات المصارف، 12% من اسمي رتبة «عقود» بعد تصفير الكسر مع توقيفاتها، والمبالغ اليدوية لكل شهر من إعدادات النسخة. يوضح حالة مطابقة التنفيذ والمبالغ الناقصة. اختُبر المنطق ببيانات وهمية؛ **تحتاج الواجهة والنتائج إلى اختبار ومطابقة على Windows قبل اعتمادها محاسبياً**.

## حدود الإصدار الحالي

- المشروع لم يُبنَ أو يُختبر على Windows بعد ولا يوجد ملف تثبيت. يتطلب البناء Windows 11 مع Visual Studio 2022 و.NET 8 وWindows App SDK. المشروع غير محزم (`WindowsPackageType=None`).
- تتوفر مقارنة الاستقطاعات بين شهرين وفحص تكرارها، وتتوفر مقارنة الرواتب للجدد والخارجين وتغير الصافي والرتبة والعمل والحساب، مع استبعاد الأسماء المكررة؛ وتتوفر فحوص IBAN والأرقام والرعاية والصافي ومطابقة الملاك، لكن النتائج لم تُطابق بالكامل مع الآيفون بعد. تصدير الكشوف الخاصة بالنماذج المعتمدة، ومعاينات ملفات التصدير ومشاركة قسيمة الراتب لم تُنفذ بعد. تقرير الملاك يحاول مطابقة النموذج المعتمد ويحتاج اختبار ويندوز قبل اعتماده. الكشوف العامة تستخدم أعمدة النموذج وألوانه وترويسة النسخة وخط Arial واتجاه اليمين، ويضيف PDF العلامة المائية وترقيم الصفحات؛ تحتاج مراجعة على ويندوز قبل استخدامها رسمياً.
- البحث يعرض أول 100 نتيجة لكل نوع، وقائمة الجهات والملاك أول 500 نتيجة، وتعرض حالة التدقيق والكشف الخاص أول 500 نتيجة في المعاينة؛ تصدير حالة التدقيق يتضمن كل النتائج. البحث في الرواتب والجهات للشهر المحدد، وفي الملاك والكتب لجميع الأشهر. قائمة الكتب تعرض الشهر المحدد.
- النسخة ونتائجها تبقى خلال تشغيل التطبيق فقط. لا يوجد تحديث تلقائي أو مخزن دائم للعمل دون اتصال؛ افتح أحدث نسخة من جديد للحصول على التغييرات.
- العنوان والرمز لا يُحفظان، ويُطلبان عند كل تنزيل. HTTP المحلي غير مشفّر؛ استخدم شبكة موثوقة فقط. تحتفظ القراءة بنسخة مؤقتة في مجلد المستخدم المؤقت للوصول إلى الكتب، وتحذفها عند فتح نسخة أخرى أو إغلاق التطبيق طبيعياً؛ قد تبقى بعد إنهاء مفاجئ. ملفات PDF التي يحفظها المستخدم تبقى في الموقع الذي يختاره.
- تُفحص أعداد الأقسام والإصدار قبل قبول النسخة، ولا تُستخرج مسارات من أرشيف ZIP. المزامنة باتجاهين تتطلب لاحقاً إصدارات للسجلات وحل التعارضات في السيرفر والآيفون.

اختبار المنطق المشترك ببيانات وهمية: `dotnet run --project WindowsApp.Tests/WindowsApp.Tests.csproj`. هذا الاختبار لا يشغل واجهة Windows ولا يثبت توافقها.
