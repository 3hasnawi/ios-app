# الرواتب لويندوز — المرحلة الأولى

نسخة WinUI 3 للقراءة فقط: فتح نسخة ZIP من التطبيق أو تنزيل آخر نسخة من السيرفر المحلي، عرض صافي الشهر وعدده وتصنيف الرتب، والبحث بأسماء الموظفين وجهات الاستقطاع. اختيار الشهر من الأشهر الموجودة في النسخة. لا تُكتب بيانات إلى السيرفر أو الآيفون، ولا تُستبدل النسخة الاحتياطية.

يتطلب البناء جهاز Windows 11 مع Visual Studio 2022 و.NET 8 وWindows App SDK؛ هذه المرحلة لم تُبنَ أو تُختبر على ويندوز بعد. المشروع غير محزم (`WindowsPackageType=None`).

- النسخة تُقرأ عند الطلب وتبقى نتائجها في الذاكرة إلى إغلاق التطبيق؛ لا يوجد تحديث تلقائي أو مخزن دائم للعمل دون اتصال في هذه المرحلة. لتنزيل التغييرات افتح أحدث نسخة مرة أخرى.
- بيانات السيرفر ورمز الوصول لا تُحفظ، ويُطلبان مجدداً عند التنزيل. الاتصال HTTP محلي غير مشفّر؛ استخدم شبكة موثوقة. أثناء التنزيل ينشأ ملف مؤقت في مجلد المستخدم المؤقت ويُحذف عند اكتمال القراءة أو عند حدوث خطأ؛ قد يبقى إذا أغلق النظام التطبيق فجأة.
- تظهر نتائج البحث حتى 100 موظف و100 جهة للشهر المحدد. الملاك والكتب تُقرأ أعدادها للتحقق لكن البحث فيها، ومعاينة الكتب والتقارير والتدقيق وكشف البنك، لم تُنفذ بعد.
- يُتحقق من إصدار النسخة وأعداد الأقسام قبل استبدال العرض الحالي. لا تُستخرج الملفات من ZIP إلى مسارات يحددها الأرشيف.
- المزامنة باتجاهين مؤجلة؛ تتطلب إدارة تعارضات وإصدارات على السيرفر والآيفون قبل تمكين الكتابة من ويندوز.
