# فحص واجهة النسخة المحلية على ويندوز

مشغّل اختبار منفصل، لا يغيّر التطبيق. يشغّل `SalaryLocal.App.App` وموارد XAML ومسار بدء التشغيل الحقيقي، ثم يستخدم أحداث أزرار التنقل الفعلية. تُستخدم قراءة الحقول الخاصة للتحقق من الجاهزية والوصول إلى المخزن، واستدعاء معالج ملف المنتسب الحقيقي. لا يعيد رسم التصميم بكود بديل.

## الأمان والتشغيل

لجهاز GitHub Actions مؤقت جديد يعمل بويندوز فقط. يرفض التشغيل دون العلامتين أدناه، ويرفض **أي مجلد SalaryLocal موجود** في LocalApplicationData قبل إنشاء التطبيق. لا تحذف بيانات حساب حقيقي لتجاوز الشرط. لا تستخدم جهاز المستخدم لهذا الفحص.

```powershell
$env:SALARYLOCAL_UI_TEST = '1'
$env:SCREENSHOT_DIR = Join-Path $env:RUNNER_TEMP 'salarylocal-ui-proof'
$env:SOURCE_COMMIT = $env:GITHUB_SHA
# GITHUB_ACTIONS=true تضبطها خدمة GitHub Actions بالفعل
 dotnet run --project windows-local/SalaryLocal.Smoke/SalaryLocal.Smoke.csproj -c Release
```

يُنشئ المخزن الحقيقي بيانات وهمية فقط: شهران، ٨ رواتب و٨ استقطاعات، أربعة سجلات ملاك، حساب TEST غير صالح عمداً للتحويل، كتاب PDF اصطناعي، قيد أمانة وفترة مطابقة. لا تُقرأ مصادر رواتب أو نسخ سابقة. بيانات الاختبار تبقى في مساحة التطبيق المؤقتة، **ولا تُنشر قاعدة البيانات أو مجلد AppData**.

انشر من SCREENSHOT_DIR فقط: صور PNG وmanifest.json وسجل تنفيذ نصي إن رغبت. يعرض الفهرس commit المصدر، إصدار التطبيق، النتيجة، جاهزية التطبيق، طريقة التقاط كل صورة وبصمتها. ينتهي الاختبار برمز غير صفري عند الخطأ أو المهلة أو فشل تحقق الجاهزية. ينبه الحساب TEST إلى فشل صحة الحساب عمداً؛ هذه ملاحظة محاسبية وليست خطأ تشغيل.

## تغطية الصور

القوائم الخمس عشرة من الرئيسية حتى النسخ ومساحات العمل، ثم ملف المنتسب، إضافات البنك، تعديل العقود، بيانات الدافع وخيارات التصدير. تُغلق النوافذ دون حفظ أو طباعة. العودة إلى الرئيسية تحقق إضافي بعد الإغلاق.

الطريقة المفضلة CopyFromScreen تلتقط النافذة الفعلية الظاهرة في سطح مكتب ويندوز، بعد التحقق أنها في المقدمة وفي حدود الشاشة وأن الصورة ليست فارغة. إن تعذر ذلك، تُحفظ صورة RenderTargetBitmap للشجرة البصرية الحقيقية للتطبيق الجاري، ويسجل الفهرس السبب صراحة. **الصورة البديلة ليست لقطة سطح مكتب ولا تشمل إطار ويندوز**. لا يُعتبر نجاح الاختبار اعتماداً محاسبياً، ولا اختباراً للطابعة أو الماسح أو تداول ملفات حقيقية.

## تحقق البناء المحلي

```sh
/tmp/payroll-dotnet build windows-local/SalaryLocal.Smoke/SalaryLocal.Smoke.csproj --no-restore -m:1 -p:UseSharedCompilation=false
```

يمكن ترجمة هدف ويندوز على لينكس؛ تنفيذ WPF والتقاط الصور يحتاجان ويندوز فعلياً. لا تُعدّ الترجمة وحدها نجاح فحص الواجهة.
