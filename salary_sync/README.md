# إضافة مزامنة الرواتب لـ Home Assistant OS

مرحلة تأسيسية ببيانات **وهمية فقط**. تحفظ نسخ JSON شهرية بإصدار وتاريخ وبصمة SHA-256 داخل `/data/snapshots.sqlite3`. نشر الشهر عملية واحدة؛ تبقى النسخة السابقة إذا رُفض الملف. صفحة الإدارة داخل Home Assistant Ingress على المنفذ الداخلي 8099. واجهة القراءة للتطبيق منفصلة على 8080 وتتطلب Bearer token يُنشئه مدير Home Assistant من صفحة الإضافة.

## التثبيت التجريبي

في Home Assistant: الإعدادات ← الإضافات ← متجر الإضافات ← قائمة النقاط الثلاث ← المستودعات، أضف:
`https://github.com/3hasnawi/ios-app`
ثم ثبّت «مزامنة الرواتب (تجريبي)» وشغّلها. إذا سبق أن فشل تثبيت 0.1.0، حدّث مستودع الإضافات من المتجر وثبّت الإصدار 0.1.1؛ إصلاح Dockerfile يستخدم صورة Python مباشرة. افتح واجهة الويب من صفحة الإضافة. منفذ 8080 **غير منشور على المضيف افتراضيًا**؛ لا تفتحه للإنترنت مباشرة. عند مرحلة ربط الآيفون، اضبطه على منفذ داخلي عبر VPN للأجهزة المخوّلة فقط، ووفّر اتصال HTTPS إذا خرجت البيانات من النفق الآمن.

للتجربة يوجد الملف `tests/sample-fake.json` بأسماء ومبالغ وهمية. أو أنشئ ملف JSON مثل:
```json
{"format":1,"month":"شهر تجريبي 2026","employees":[{"name":"موظف وهمي","netSalary":1000}],"deductions":[]}
```
اختر الملف في صفحة الإضافة، راجع الأعداد، ثم اعتمد النشر. أنشئ رمز قارئ وخزّنه بأمان. واجهة القراءة: `GET /v1/months` و`GET /v1/months/{month}` مع `Authorization: Bearer <token>`، وتعطي النسخة الأخيرة فقط. إلغاء رمز أو تعيين صلاحيات فردية وربط SwiftData في التطبيق **لم يُنفَّذ بعد**؛ لا تستخدم الإضافة لملفات الرواتب الفعلية الآن.

## الخطوات التالية قبل بيانات حقيقية

1. تحديد مخطط البيانات بين SwiftData والسيرفر، والتحقق من أعداد الرواتب والاستقطاعات ومجاميعها قبل النشر.
2. حسابات منفصلة، إلغاء الرموز، وتدقيق من نشر ومن قرأ؛ حماية واجهة الوصول داخل VPN.
3. مزامنة تدريجية في تطبيق الآيفون وتبديل محلي ذري بعد اكتمال التنزيل والتحقق من البصمة، مع المحافظة على عمله دون إنترنت.
4. نسخ احتياطي مشفّر خارج الـ mini PC وتجربة الاسترجاع؛ قياس الأداء ببيانات وهمية بحجم 29 ألف راتب و42 ألف ملاك.

وجود قاعدة البيانات في `/data` يجعلها ضمن نسخ Home Assistant الاحتياطية. تبقى نسخة خارج الجهاز ضرورية إذا تعطل القرص.
