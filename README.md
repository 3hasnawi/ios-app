# تطبيق الرواتب (iOS)

> 📌 **تعليمات العمل على المشروع وتفاصيله الحالية في [`AGENTS.md`](AGENTS.md)** — ما يلي قد يكون قديماً.

تطبيق آيفون يستورد ملفات Excel، ويحفظها في قاعدة بيانات داخل الجهاز (SwiftData)، ويتيح البحث بالاسم.
يعرض لكل موظف: **الاسم، الرتبة، محل العمل، صافي الراتب**، وتحتها **الاستقطاعات** باسمه إن وُجدت.

> ⚠️ ملفات الرواتب (`.xlsx`) لا تُرفع إلى المستودع (مستثناة في `.gitignore`).
> الملف يُستورد على الآيفون مباشرة من تطبيق "الملفات".

## شكل ملف Excel

يتعرف التطبيق على الأوراق والأعمدة من **العناوين** (ترتيب الأعمدة غير مهم):

**ورقة الرواتب**: فيها عمود الاسم (`Name_m` أو `الاسم`) و`صافي الراتب`.
- الرتبة: `الرتبة`
- محل العمل: `NO_markaz` (أو `محل العمل` / `القسم` / `اسم المديرية`)
- أعمدة الاستقطاع داخل ورقة الرواتب (مثل `اسم الاستقطاع` / `مبلغ الاستقطاع`) **لا تُقرأ**.

**ورقة الاستقطاعات**: فيها `الاسم` و`المبلغ` بدون صافي راتب، وهي **المصدر الوحيد** للاستقطاعات.
- نوع الاستقطاع: `اسم الفرع` (أو `نوع الاستقطاع` / `الجهة`)
- ملاحظة: `الملاحظات`

يُربط الاستقطاع بالموظف عن طريق الاسم (بعد توحيد الهمزات وحذف المسافات) ضمن نفس الشهر.

## الأشهر

- **كل ملف = شهر** باسم الملف، مثل `تشرين الاول 2026.xlsx` ← شهر «تشرين الاول 2026».
- يمكن اختيار عدة ملفات مرة واحدة في نافذة الاستيراد.
- استيراد ملف بنفس اسم شهر موجود **يستبدل ذلك الشهر فقط**، والأشهر الأخرى تبقى.
- **قائمة الشهر** في أعلى الشاشة: تختار منها الشهر الذي تبحث فيه، ومنها تحذف بيانات شهر.
- الأشهر مرتبة زمنياً إذا كان اسم الملف يحتوي اسم الشهر والسنة
  (تشرين الأول/كانون الثاني/شباط… أو أكتوبر/يناير… أو أرقام مثل `2026-10`).

## البناء على GitHub (بدون Mac)

1. ارفع هذا المجلد إلى مستودع على GitHub (فرع `main`).
2. كل `push` يشغّل **Actions ← Build iOS app** تلقائياً (أو شغّله يدوياً من زر *Run workflow*).
3. بعد انتهاء البناء (حوالي 5–10 دقائق) يُنشر ملف `SalaryApp.ipa` في صفحة الإصدارات (Releases). آخر نسخة دائماً على:
   https://github.com/3hasnawi/ios-app/releases/latest/download/SalaryApp.ipa

## التثبيت على الآيفون من Windows

ملف الـ IPA غير موقّع، ويوقّعه برنامج تثبيت بحساب Apple ID الخاص بك:

1. ثبّت [Sideloadly](https://sideloadly.io) على Windows (يحتاج iTunes وiCloud من موقع Apple).
2. صِل الآيفون بالكابل، اسحب ملف `.ipa` إلى Sideloadly، وأدخل Apple ID.
3. على الآيفون: الإعدادات ← عام ← VPN وإدارة الأجهزة ← وثّق حسابك.
4. فعّل **وضع المطوّر**: الإعدادات ← الخصوصية والأمان ← وضع المطوّر.

مع حساب Apple مجاني ينتهي التوقيع بعد 7 أيام ويلزم إعادة التثبيت (البيانات تبقى).
للتوزيع على عدة أجهزة عبر TestFlight يلزم حساب مطوّر مدفوع (99$ سنوياً) وإضافة شهادات التوقيع إلى GitHub Secrets.

## المشاركة

في صفحة الموظف زر **مشاركة** (وفي نتائج البحث: اسحب السطر أو اضغط عليه مطولاً).
تظهر نافذة فيها معاينة النتيجة وثلاثة خيارات:
- **نسخ كصورة**: تُنسخ الصورة للصقها في واتساب أو الملاحظات.
- **تصدير PDF**: حفظ في الملفات أو الطباعة أو الإرسال.
- **مشاركة كصورة**: إرسال الصورة إلى أي تطبيق.
