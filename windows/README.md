# تطبيق الرواتب — نسخة ويندوز قيد التطوير

هذه مرحلة تطوير غير معتمدة وليست بديلاً مكتملاً عن الآيفون. طابق النتائج مع الآيفون قبل الاعتماد. لا تنشئ الكتب أو تحفظ تعديلات الرواتب؛ كشف المطابقة المتاح مسودة للمراجعة فقط. استيراد Excel ومزامنة النسخ لا يزالان غير مكتملين.

## المتاح حالياً

- قراءة نسخة ZIP من الآيفون حتى الإصدار 5 محلياً دون تعديلها، مع فحص الإصدار وأعداد السجلات وفهرس الأرشيف.
- عرض الأشهر حسب ترتيب فهرس النسخة، ومجموع الصافي المتوفر، والتنبيه عند وجود مبالغ ناقصة.
- عرض وبحث الرواتب والاستقطاعات وجهات التنفيذ وحسابات الجهات وفهرس الأرشيف، وفتح الكتب من النسخة محلياً.
- عرض كشف البنك المحسوب من الرواتب والاستقطاعات والمبالغ اليدوية، مع تنبيهات نقص البيانات وعدم المطابقة. يجب مراجعته مع الآيفون.
- عرض وإضافة وتعديل فترات وحركات مطابقة الحساب، وتأشير المطابقة وربط المبالغ المسترجعة، مع حفظ محلي مستقل مرتبط بالنسخة المفتوحة. تُعرض مقترحات المصادر المكتملة للمراجعة مع تنبيه تغير المصدر ومنع تكراره؛ لا تُثبت عملية المصرف تلقائياً. تصدير مسودة كشف PDF بخط النظام يحتاج مراجعة بصرية على ويندوز. لا تُدمج تعديلات نسختين تلقائياً. يمكن حفظ نسخة ZIP تشمل دفتر المطابقة؛ يجب اختبار استعادتها على الآيفون قبل الاعتماد.
- تجهيز ملف CSV للمجموعتين بعد فحص المصادر والحسابات والجهة الدافعة والترميز والصفوف، ومنع التصدير عند وجود مشكلات. يمكن ربط الجهة بحساب مستورد وتحديد مجموعتها؛ التصنيف المخالف للحساب يظهر مشكلة تمنع التصدير. تعديل بيانات الحسابات والكتاب المرافق لم يكتمل بعد.
- تُحفظ نسخة محلية بعد التحقق منها وتُفتح تلقائياً، مع إبقاء النسخ السابقة وعدم تعديل الملف المستورد. تشمل النسخة المصدّرة روابط الحسابات وتصنيفاتها ودفتر المطابقة ولا تتضمن ملفات CSV المنفصلة؛ استعادة الآيفون تحتاج اختباراً. عند فتح كتاب تُنشأ نسخة مؤقتة وقد تبقى إن ظلت مفتوحة في برنامج آخر.

## التطوير

يلزم .NET 10 SDK. على Windows 11:

```powershell
dotnet build windows/SalaryDesktop.sln
dotnet run --project windows/SalaryDesktop/SalaryDesktop.csproj
```

يمكن بناء المشروع من لينكس باستخدام `EnableWindowsTargeting`، لكن ذلك لا يختبر تشغيل WPF على ويندوز. اختبارات النواة تستخدم بيانات وهمية:

```powershell
dotnet run --project windows/SalaryDesktop.Tests/SalaryDesktop.Tests.csproj
```

يُشغّل إجراء `windows-check.yml` يدوياً للتحقق على Windows من البناء والاختبارات وبدء التطبيق فقط؛ لا يعد اختباراً شاملاً للواجهة أو المستندات. لا تضع نسخاً احتياطية أو ملفات رواتب أو بيانات حقيقية في المستودع.
