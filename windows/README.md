# نسخة ويندوز الجديدة — مرحلة تأسيسية

هذه مرحلة قراءة محلية أولية، وليست بديلاً مكتملاً عن تطبيق الآيفون. تدعم فتح نسخة ZIP، واستعراض الرواتب والاستقطاعات والبحث فيها، ومقارنة مجاميع الاستقطاعات بين شهرين بحسب اسم الجهة كما ورد حرفياً. تُبيّن المقارنة المبالغ الناقصة ولا تعرض فرقاً نهائياً عندما ينقص مبلغ. بيانات الرواتب المفهرسة محلياً تقتصر على أحدث شهرين؛ تبقى الاستقطاعات لجميع الأشهر، وتُحفظ نسخة ZIP الأصلية كاملة كما هي، بما فيها الرواتب الأقدم والكتب والإعدادات. لذلك تحتاج العملية إلى مساحة إضافية لنسخ الملف وقاعدة البيانات. لا يتم تعديل ملف المصدر.

الأرشيف يتيح البحث في الكتب المحفوظة في نسخة الآيفون، وفتح نسخة مؤقتة في عارض PDF الافتراضي أو حفظ نسخة PDF إلى موقع يختاره المستخدم. يُحاول البرنامج حذف نسخ المعاينة المؤقتة عند إغلاقه؛ قد تبقى إذا كان عارض PDF يحتفظ بالملف مفتوحاً. لا يدعم الأرشيف بعد إضافة الكتب أو تعديلها أو مزامنتها مع الآيفون.

يتحقق الاستيراد من شكل الحزمة وبعض محتوياتها وأعداد السجلات، لكنه ليس تحققاً شاملاً من دلالات كل إعداد وكتاب. لا توجد حالياً إمكانية تعديل البيانات أو إرجاع نسخة إلى الآيفون. كشف البنك والكتب والكشوف والتصدير وبقية وظائف الآيفون لم تُنفذ بعد. لا يُستخدم هذا الإصدار لاعتماد نتائج محاسبية أو كبديل وحيد للنسخة الاحتياطية.

البيانات المحلية في `%LOCALAPPDATA%\IraqiPayrollNew` مستقلة عن مجلد البرنامج. كل استيراد ينشئ مجلداً جديداً ويحتفظ بالاستيرادات السابقة، ولا ينظفها تلقائياً. لا يحذف المثبّت هذه البيانات عند التحديث أو إزالة البرنامج. احفظ نسخة احتياطية مستقلة على iCloud أو وسيط آمن.

## البناء والاختبار على ويندوز

المتطلبات: .NET 10 SDK وInno Setup 6. من جذر المستودع:

```powershell
dotnet build windows/PayrollWindows.sln -c Release
dotnet test windows/PayrollWindows.sln -c Release
./windows/build-installer.ps1
```

النتيجة `windows/installer/output/PayrollWindows-Setup.exe`: ملف تثبيت واحد لحساب المستخدم، يتضمن بيئة التشغيل. ملف التثبيت لا يصبح جاهزاً للتوزيع إلا بعد نجاح اختباره على ويندوز واكتمال الوظائف المطلوبة.
