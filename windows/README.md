# تطبيق الرواتب — نسخة ويندوز الأولية

هذه مرحلة تطوير للعرض فقط، وليست بديلاً معتمداً عن الآيفون. لا تنشئ تحويلات أو كتباً أو كشوف مطابقة، ولا تحفظ تعديلات الرواتب، ولا تكتب نسخة احتياطية. البرامج المصرفية والتدقيق والتصدير واستيراد Excel ومزامنة النسخ لا تزال غير مكتملة.

## المتاح حالياً

- قراءة نسخة ZIP من الآيفون حتى الإصدار 5 محلياً دون تعديلها، مع فحص الإصدار وأعداد السجلات وفهرس الأرشيف.
- عرض الأشهر حسب ترتيب فهرس النسخة، ومجموع الصافي المتوفر، والتنبيه عند وجود مبالغ ناقصة.
- عرض وبحث الرواتب والاستقطاعات وجهات التنفيذ وحسابات الجهات وفهرس الأرشيف.
- عرض تفاصيل المنتسب وبنود راتبه من البيانات الموجودة في النسخة، وفتح نسخة مؤقتة من كتاب الأرشيف بعارض PDF في ويندوز.
- بيانات النسخة تبقى في الذاكرة خلال الجلسة، وتحتاج إعادة فتح الملف بعد إعادة تشغيل البرنامج. إذا بقي PDF مفتوحاً خارج البرنامج فقد تبقى نسخته المؤقتة في مجلد ملفات النظام المؤقتة.

## التطوير

يلزم .NET 10 SDK. على Windows 11:

```powershell
dotnet build windows/SalaryDesktop.sln
dotnet run --project windows/SalaryDesktop/SalaryDesktop.csproj
```

يمكن بناء المشروع من لينكس باستخدام `EnableWindowsTargeting` الموجود في المشروع، لكن ذلك لا يختبر تشغيل WPF على ويندوز. اختبارات النواة تستخدم بيانات وهمية وتعمل على .NET دون واجهة:

```powershell
dotnet run --project windows/SalaryDesktop.Tests/SalaryDesktop.Tests.csproj
```

لا تضع نسخاً احتياطية أو ملفات رواتب أو بيانات حقيقية في المستودع. يجب مراجعة التطابق مع الآيفون واختبار وظائف ويندوز فعلياً قبل أي استخدام محاسبي.
